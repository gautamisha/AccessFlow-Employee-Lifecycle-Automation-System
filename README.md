# AccessFlow-Employee-Lifecycle-Automation-System
ython-based employee lifecycle automation system for onboarding, role changes, offboarding, approval workflows, access validation and audit logging using Flask and MySQL.
AccessFlow is a Python-based IT workflow automation application designed to simplify employee onboarding, role changes and offboarding processes.

The system simulates employee lifecycle workflows by managing access requests, approval stages and employee information through a centralized platform. It validates employee details, checks for duplicate requests, tracks workflow progress and maintains audit logs of every action.

Key Features

Employee Onboarding: Creates onboarding requests and generates checklists for required accounts, software licenses and device assignments.

Role Change Management: Manages employee department and role changes with appropriate approval workflows.

Employee Offboarding: Simulates account deactivation requests and tracks device and access-removal checklists.

Approval Workflow: Supports manager approval and rejection of employee lifecycle requests.

Access Validation: Checks employee records, role details and duplicate requests before processing actions.

Audit Logging: Maintains a history of request submissions, approvals and workflow status changes.

Request Tracking: Provides a centralized view of pending, approved and completed requests.

Technology Stack

Python, Flask, MySQL, REST APIs, HTML, CSS and JavaScript.

Objective

To reduce repetitive manual IT administration tasks by automating employee lifecycle workflows, improving request tracking and introducing validation and auditability into access management processes.
